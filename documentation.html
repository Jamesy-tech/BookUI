BookUI Command Panel BookUI is a bookmarklet that opens a command panel inside your browser. You can run code in it with or without knowing JavaScript. It's made to be simple to use and quick to set up.

https://jamesy-tech.github.io/BookUI
Features
  • Opens a command-style panel on any page
  • Lets you run JavaScript instantly
  • Works for both beginners and coders
  • No extensions or installs needed
Website Compatibility
Please note: BookUI does not work on ALL websites due to security reasons. Try it on Google Search, Jamesy-tech, Wikipedia, or your favorite news website. BookUI should work on most websites.

Examples where BookUI does NOT work: Google Docs, Google Classroom, YouTube, Discord, Reddit, Instagram, Facebook.
How to Get It 1. Go to https://jamesy-tech.github.io/AddBookUI
2. Drag & drop the BookUI button into your browser's bookmarks bar.

You're done!
What It Does When you click on BookUI, it adds a small panel that appears over the page. You can type code in it or use the buttons to perform actions. Try having a bit of fun editing Google.
Example Uses
  • Try small JavaScript commands
  • Edit or test code on a website
  • Learn how code affects pages directly
